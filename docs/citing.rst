Citing ancestree
================

If you use ``ancestree`` in your research, please cite the following `paper <https://doi.org/10.64898/2026.09.11.750934>`__:

.. code-block:: bibtex

    @article{ancestree,
        author = {Sendrowski, Janek and Bataillon, Thomas},
        title = {Ancestree: unified likelihood inference of ancestral alleles under supplied or inferred genealogies},
        journal = {bioRxiv},
        year = {2026},
        doi = {10.64898/2026.09.11.750934},
        url = {https://doi.org/10.64898/2026.09.11.750934}
    }
